# 安全问题 / Security

Glintile 在浏览器内处理图片，并校验导入的 JSON。图片解码由浏览器完成，特别大的图片可能占用较多内存。

如果发现数据丢失、脚本执行或作品意外外传等问题，请通过[联系入口](https://www.brothforge.com/faq/policy.html#policy-q01)提供浏览器版本、复现步骤和去除个人信息的最小示例。敏感信息及尚未修复的漏洞细节请不要放在公开 Issue 中。

本地预览服务仅监听 `127.0.0.1`；对外部署请使用静态托管服务。

## English

Glintile processes images in the browser and validates imported JSON. Large images may use substantial memory during browser decoding.

For security issues, use the [contact page](https://www.brothforge.com/faq/policy.html#policy-q01) and include your browser version, reproduction steps and a minimal example without personal information. Keep sensitive data and details of unpatched vulnerabilities out of public Issues.
