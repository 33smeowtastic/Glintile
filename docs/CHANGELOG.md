# 更新记录

## 1.0.1（预览）

- 新增本机作品库，可命名保存多幅作品，并继续编辑、改名、复制、删除或覆盖。
- 支持复制和粘贴项目 JSON，同时保留原有 JSON 文件导入与导出。
- 删除和覆盖使用应用内确认，取消为默认焦点，支持 Esc，并检查待操作的存档是否已变化。

## 1.0.0（预览）

- 在本机导入图片、编辑 LED 点阵，保存 JSON 或导出 PNG。
- 黑猫与骨头参考图支持完整浏览、独立缩放和平移，并保留转图取景。
- 顶部使用保存与网页分享图标，恢复暂存提示分为说明和操作两行。
- 左上角组合点阵 G 图标和专门绘制的中英文字标，分享和反馈回礼沿用站群图标。
- 提供离线安装和更新提示，作品继续保存在当前浏览器。
- 无法识别或损坏的暂存保留原始记录，可先备份；导出和自动保存不会覆盖它。
