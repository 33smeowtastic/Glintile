# 测试指南

## 运行测试

```sh
npm ci
npm test
npx playwright install chromium
npm run test:e2e
```

浏览器测试也支持通过 `CHROME_PATH` 使用已安装的 Chrome。测试启动本机临时服务，结果与截图写入 `artifacts`。

## 覆盖内容

17 项单元与构建测试覆盖原生点阵数据、JSON 校验、栅格输出、构建内容、安装清单、资源完整性、许可文件、版本递增规则，以及中英文字标、PWA 图标与站群分享/反馈图标。

29 项 Chrome 浏览器回归覆盖：

- PWA 注册、离线冷启动，以及静态托管的 `index.html` 重定向。
- 示例编辑、JSON 导出、撤销后的缩放与位置。
- 参考图取景、提亮与饱和度、转图预览。
- 320、390、430、844 和 1440 像素宽度的布局。
- 手机上下对照的参考区尺寸、双指缩放、拖动、全图适配和整页滚动。
- 两项内置作品在六种屏幕尺寸及四种参考模式下的完整显示；浏览操作保留取景、采样结果和作品。
- 草稿恢复、备份、取消操作与保存保护，以及两行暂存提示和图标按钮布局。
- 未知版本、损坏 JSON、空记录、旧版共存和读取失败时的暂存保护；原样备份、导出、自动保存、取消导入及明确替换。
- 分享正式网页链接、取消分享、重复点击、剪贴板及手动复制后备流程。
- 站群反馈回礼入口、键盘访问，以及离开前取消操作对未保存作品的保护。
- 完整性校验、更新提示、取消更新和确认更新。

测试服务器可模拟 Cloudflare Pages 将 `index.html` 重定向到目录根路径的行为，用于覆盖线上托管与本地预览的差异。

## 持续集成

[GitHub Actions](https://github.com/33smeowtastic/Glintile/actions) 在 Pull Request 和 main 分支推送时运行构建与测试。环境固定为 Ubuntu 24.04，与项目使用的 Playwright 版本保持兼容。

## 设备检查

自动化覆盖 Chrome 和模拟视口。发布面向移动端的改动时，也请在实际设备上检查安装入口、横竖屏、离线启动和保存操作；Safari 的“添加到主屏幕”等行为由浏览器提供。
